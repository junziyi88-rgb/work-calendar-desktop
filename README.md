# 工作日历

一款仅在本机保存数据的 Windows 工作日历，用来安排未来任务、记录实际投入，并在每天结束时复盘时间分布。

## 主要功能

- 日、周、月视图，默认进入周视图
- 拖拽创建计划或补记实际工作，拖动和拉伸可调整时间
- 自动计时、手动补录、多段时间记录和可选并行计时
- 计划时间与实际时间分层显示
- 项目、标签、状态、搜索与筛选
- 每日复盘、七日洞察、计划偏差和项目占比
- 系统托盘、全局快捷键和悬浮计时器
- 休眠时间确认、即将开始、逾期和长计时提醒
- SQLite 本地存储、回收站、每日备份与安全恢复
- CSV、JSON 和 ICS 导出
- 浅色、深色和跟随系统主题

## 安装

运行 `release/WorkCalendar-Setup-1.0.0.exe`，选择安装位置即可。应用关闭主窗口后会继续驻留系统托盘；需要完全退出时请使用托盘菜单中的“退出”。

## 快速开始

1. 在周日历的空白处拖动，划出一段计划时间。
2. 使用工具栏中的“计划 / 补记”切换拖拽创建的记录类型。
3. 打开任务并点击“开始计时”，主窗口关闭后计时仍会继续。
4. 下班前进入“复盘”，查看实际投入、完成率和未完成计划。

默认全局快捷键是 `Ctrl+Shift+Space`，用于打开快速添加。

## 数据与备份

应用无需登录，也不会上传数据。SQLite 数据库和每日备份存放在 Windows 当前用户的应用数据目录中。可以在“设置”中手动备份、恢复和导出数据。

## 开发与验证

```powershell
npm install
npm test
npm run typecheck
npm run build
npm run dist
```

要求 Node.js 22 或更高版本。Electron、React、TypeScript、Vite、Vitest、FullCalendar、Zustand、Zod 和 sql.js 构成主要技术栈。
