# 工作记录

一款完全保存在本机的 Windows 工作日志。做完一件事后手动写一句、填写工时，同一个长期事项可以持续记录数周或数月；周末和月底直接复制整理好的总结。

## 主要功能

- 十秒内完成一条手动工作记录
- 工时支持 `1.5h`、`90m`、`1小时30分` 等自然输入
- 长期事项进展时间线，适合多任务并行
- 可把日期不确定的进展直接记到某一周
- 自动生成每周工作总结
- 按事项统计每月工时并生成 OKR 素材
- CSV 工时导出和 JSON 完整备份
- SQLite 本地保存和每日静默备份
- 浅色、深色和跟随系统主题

应用不包含自动计时、计划日历、任务提醒、项目层级、标签或复杂状态流。

## 安装

运行 `release/WorkLog-Setup-1.1.0.exe`。安装程序默认创建桌面快捷方式和开始菜单快捷方式，名称均为“工作记录”。关闭主窗口会直接退出应用。

## 日常使用

1. 打开“记录”。
2. 选择一个已有事项，或者直接输入新事项名称。
3. 写下这次完成了什么，填写工时并保存。
4. 在“事项”中查看跨天、跨周的完整进展。
5. 在“总结”中复制周总结或月度 OKR 素材。

## 数据

数据不会上传。旧版“工作日历”的任务和实际时间会在首次启动新版时迁移为事项和工作记录；原有项目、标签及旧表不会被删除。迁移前会创建安全备份。
